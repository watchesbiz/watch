# Maintenance Log Template

One page per watch. Copy the blocks below into a note file, a spreadsheet, or a printed sheet in the box — the format does not matter, the consistency does.

Why bother: a documented history is what makes a service decision defensible, what an insurer asks for after a loss, and what a buyer pays a premium for. See [INSURANCE-AND-RECORDS](INSURANCE-AND-RECORDS.md) for the evidence side.

## 3. Rate and amplitude measurements

Measure full wind, after 1 hour of running, at a stable room temperature. Two positions minimum: **DU** (dial up) and **CD** (crown down). Add **CU** and **9U** if you are diagnosing.

| Date | Position | Rate (s/d) | Amplitude (°) | Beat error (ms) | Notes |
|---|---|---|---|---|---|
| | DU | | | | First measurement after purchase |
| | CD | | | | |
| | DU | | | | |
| | CD | | | | |

How to read the trend: **amplitude falls before rate does.** Amplitude below 240° is the trigger to book a service, even if the watch is still keeping time. See [SERVICE-INTERVALS](SERVICE-INTERVALS.md).

| | | | | | | | |

For each service, also record:

- ☐ Gaskets replaced (caseback, crown, crystal, pushers)
- ☐ Mainspring replaced
- ☐ Crystal replaced
- ☐ Case refinished — note that this removes metal
- ☐ Pressure test performed — **result: ____ bar**

Ask for the before/after amplitude and rate in writing and keep the slip. A watchmaker who cannot produce those numbers did not measure the watch.

## Minimal version

If the full template is too much, keep just these four things. They cover 90% of the value:

1. **Serial number, as text**
2. **Amplitude and rate, once a year, in two positions**
3. **Service dates, with gaskets noted**
4. **A dated photo set, once a year**
